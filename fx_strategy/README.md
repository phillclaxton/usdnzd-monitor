# FX Strategy Manager

Monitor and manage a staged foreign exchange conversion strategy from inside
Home Assistant.

**This app is a decision-support tool. It does not provide financial advice and
does not automatically transfer or convert money.**

Set a total amount, a ladder of target rates, and a deadline. The app watches
the rate, shows what a conversion would produce after fees, notifies you when a
target is reached, and records what you actually converted so your blended rate
stays accurate.
